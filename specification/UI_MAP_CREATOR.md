# 見取り図作成UI仕様

## 0. 現行実装同期（2026-07-15）

- レイアウトは単一固定ではなく複数作成・選択・削除できる。名前は一意で、デフォルトレイアウトは削除不可。
- オブジェクト種別は `machine / wall / path / area / stairs / entrance`。配置、移動、サイズ変更、削除、保存を提供する。
- 機械オブジェクトは機械マスタと割当コードに連携する。機械マスタ編集とオブジェクト種別色変更は admin 限定。
- レイアウト取得はログイン利用者共通、作成・保存・削除・色変更は admin 限定である。`owner_user` 列はあるが、全レイアウトを利用者別に隔離する仕様ではない。
- `background_image_path` 列とUI入力の名残はあるが、現行 serializer は背景画像値を永続化しない。背景画像機能は未実装として扱う。

レイアウト編集権限は admin のみとする。複数adminによる同時編集・上書き競合の制御は未実装であり、正式リリース前に受入試験を行う。

## 1. 目的

* 工場内の巡回対象機械を視覚的に把握できるようにする。
* 見取り図上に機械や通路を配置し、巡回ガイド表示に利用する。
* レイアウト変更時にGUI上から編集可能な構成とする。
* 将来的な経路案内、巡回最適化、設備情報拡張に耐えられる構造とする。

---

## 2. 基本方針

* 見取り図はグリッドベースで管理する。
* 実際の座標はピクセルではなくグリッド単位で保持する。
* 背景画像は現行未実装であり、入力・保存・表示しない。実データはグリッド情報を正とする。
* MVPでは rectangle ベースの簡易レイアウトのみ扱う。
* polygon や自由描画はMVP対象外とする。

---

## 3. 画面構成

### 3.1 見取り図表示画面

巡回時に利用する閲覧専用画面。

表示内容:

* 見取り図
* 当日対象機械の強調表示
* 機械ツールチップ
* 検査対象数表示

---

### 3.2 見取り図編集画面

管理者向けレイアウト編集画面。

編集可能内容:

* オブジェクト追加
* オブジェクト削除
* ドラッグ移動
* サイズ変更
* 複数レイアウトの作成・選択
* レイアウト保存

---

## 4. グリッド仕様

* 見取り図は固定グリッド上で管理する。
* MVPでは `50 x 50` を初期値としてよい。
* オブジェクト位置は `grid_x`, `grid_y` で保持する。
* サイズは `width`, `height` で保持する。

---

## 5. オブジェクト種別

MVPでは以下を対象とする。

| type     | 用途  |
| -------- | --- |
| machine  | 機械  |
| wall     | 壁   |
| path     | 通路  |
| area     | エリア |
| stairs   | 階段  |
| entrance | 出入口 |

補足:

* machine は `machines` テーブルと紐付け可能とする。
* wall は通行不可領域として扱う。
* path は巡回導線表現に利用可能とする。

---

## 6. 編集UI仕様

### 6.1 オブジェクト追加

* オブジェクト種別を選択して配置可能とする。
* machine 選択時は機械マスタから対象機械を選択する。

### 6.2 移動

* オブジェクトはドラッグ操作で移動可能とする。
* 移動時はグリッドへ吸着する。

### 6.3 サイズ変更

* rectangle のみサイズ変更可能とする。
* サイズ変更時もグリッドへ吸着する。

### 6.4 削除

* 選択中オブジェクトを削除可能とする。

---

## 7. 背景画像

* 現行未実装。API入力値は空文字へ正規化され、保存・表示されない。
* 将来実装する場合は、アップロード制限、配信権限、保存先、版管理を別途定義する。

---

## 8. 巡回ガイド連携

* 当日検査対象と machine_assignments を照合する。
* 該当機械を見取り図上で強調表示する。
* ツールチップには以下を表示する。

表示内容:

* 機械名
* 機械番号
* 当日対象コード数

---

## 9. MVP制限事項

MVPでは以下を対象外とする。

* polygon
* 自由描画
* レイヤー機能
* ズーム編集
* 回転編集
* 最短経路探索
* リアルタイム設備状態表示
* モバイル編集UI

---
