# 見取り図作成UI仕様

## 1. 目的

* 工場内の巡回対象機械を視覚的に把握できるようにする。
* 見取り図上に機械や通路を配置し、巡回ガイド表示に利用する。
* レイアウト変更時にGUI上から編集可能な構成とする。
* 将来的な経路案内、巡回最適化、設備情報拡張に耐えられる構造とする。

---

## 2. 基本方針

* 見取り図はグリッドベースで管理する。
* 実際の座標はピクセルではなくグリッド単位で保持する。
* 背景画像は補助表示として扱い、実データはグリッド情報を正とする。
* MVPでは rectangle ベースの簡易レイアウトのみ扱う。
* polygon や自由描画はMVP対象外とする。

---

## 3. 画面構成

### 3.1 見取り図表示画面

巡回時に利用する閲覧専用画面。

表示内容:

* 見取り図
* 当日対象機械の強調表示
* 機械ツールチップ
* 検査対象数表示

---

### 3.2 見取り図編集画面

管理者向けレイアウト編集画面。

編集可能内容:

* オブジェクト追加
* オブジェクト削除
* ドラッグ移動
* サイズ変更
* 背景画像設定
* レイアウト保存

---

## 4. グリッド仕様

* 見取り図は固定グリッド上で管理する。
* MVPでは `50 x 50` を初期値としてよい。
* オブジェクト位置は `grid_x`, `grid_y` で保持する。
* サイズは `width`, `height` で保持する。

---

## 5. オブジェクト種別

MVPでは以下を対象とする。

| type     | 用途  |
| -------- | --- |
| machine  | 機械  |
| wall     | 壁   |
| path     | 通路  |
| area     | エリア |
| stairs   | 階段  |
| entrance | 出入口 |

補足:

* machine は `machines` テーブルと紐付け可能とする。
* wall は通行不可領域として扱う。
* path は巡回導線表現に利用可能とする。

---

## 6. 編集UI仕様

### 6.1 オブジェクト追加

* オブジェクト種別を選択して配置可能とする。
* machine 選択時は機械マスタから対象機械を選択する。

### 6.2 移動

* オブジェクトはドラッグ操作で移動可能とする。
* 移動時はグリッドへ吸着する。

### 6.3 サイズ変更

* rectangle のみサイズ変更可能とする。
* サイズ変更時もグリッドへ吸着する。

### 6.4 削除

* 選択中オブジェクトを削除可能とする。

---

## 7. 背景画像

* 背景画像を見取り図へ設定可能とする。
* 背景画像は配置補助用途とする。
* 背景画像変更によってレイアウトデータは変化しない。

---

## 8. 巡回ガイド連携

* 当日検査対象と machine_assignments を照合する。
* 該当機械を見取り図上で強調表示する。
* ツールチップには以下を表示する。

表示内容:

* 機械名
* 機械番号
* 当日対象コード数

---

## 9. MVP制限事項

MVPでは以下を対象外とする。

* polygon
* 自由描画
* レイヤー機能
* ズーム編集
* 回転編集
* 最短経路探索
* リアルタイム設備状態表示
* モバイル編集UI

---

## 10. 将来拡張

将来的に以下の拡張を想定する。

* 巡回経路最適化
* 通行不可領域考慮
* IoT設備状態表示
* ヒートマップ表示
* 危険区域表示
* センサー配置
* SVGベース高機能表示
* polygon対応
